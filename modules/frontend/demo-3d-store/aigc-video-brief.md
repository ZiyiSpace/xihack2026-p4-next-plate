# AIGC 视频生成提示词（Brief）

> 用途：给即梦 AI / 可灵 Kling / 海螺 / Runway 等文生视频模型直接粘贴。
> 建议策略：**开场氛围用 AIGC，功能演示用真实页面录屏**（`demo-3d-store` 页面自带演示模式，OBS/QuickTime 录屏即可）。原因见文末。

## 一、开场氛围视频（文生视频，15s，16:9）

**正向提示词：**

```
夜晚中式旋转小火锅餐厅内景，环绕镜头缓缓推进。中央是一口冒着热气的鸳鸯火锅，
蒸汽在暖黄色灯光下升腾。环形传送带缓缓转动，上面摆满色彩鲜艳的菜品小盘：
金黄色小馒头、橙色南瓜饼、深红色腌牛肉、白色鱼丸。镜头低角度掠过传送带，
菜品虚化滑过前景。周围坐满顾客的剪影，有人伸筷夹起一盘菜。
色调：暖黄+深棕，电影感打光，浅景深，画面细腻，商业美食广告质感。
结尾镜头缓缓拉高变成俯拍，整个环形传送带像一块发光的表盘。
```

**负向提示词：**

```
文字，字幕，水印，界面，数字，变形的手，多余肢体，模糊，低画质，卡通
```

**备选镜头（30s 版可追加）：**

```
俯拍视角，夜视监控风格：环形传送带缓缓旋转，三个固定机位摄像头红点闪烁，
传送带上方浮现半透明蓝色科技感扫描线扫过每个餐盘。冷蓝色调与店内暖光形成对比，
赛博感数据可视化氛围，不出现任何具体文字和数字。
```

## 二、产品概念视频（文生视频，10s，16:9）

> ⚠️ 注意：AIGC 模型渲染中文 UI 和数字必然是乱码/糊的，所以这一段只做"氛围概念"，
> 真实的界面演示请用录屏。

```
科技感未来的旋转火锅店，环形传送带上方悬浮着半透明的全息数据面板，
面板散发蓝光但内容模糊不可读。一个餐盘上的食物量逐渐减少，
全息面板随之亮起红色警示光圈，一只机械臂将一碟新菜平稳放上传送带。
镜头侧移跟拍新菜盘加入传送带环流。冷蓝+暖橙双色打光，科幻产品广告质感，
画面流畅，无文字。
```

## 三、为什么功能演示不要用 AIGC 生成

1. **数据是真的才有说服力**：我们的核心卖点是"真实可跑的系统"（数据集回放对评 8/8、认菜校验 6/6）。AIGC 视频里的界面和数字是模型幻觉，评审追问"这个页面在哪、数字哪来的"就穿帮。
2. **中文字幕/数字渲染差**：所有视频生成模型都画不好中文 UI，出来的 KPI 数字必是乱码。
3. **不可控**：改一个数字、换一个菜名都要重抽卡，今晚封版前耗不起。
4. **录屏 = 零成本的视频版**：`demo-3d-store/index.html` 打开后自带 3 分钟完整剧本（取用→补菜闭环→传感器尖峰→复秤恢复→滞留撤盘），QuickTime（⌘⇧5）录屏即得，数据全部来自真实后端逻辑。

## 四、推荐的演示片结构（5 分钟现场 / 2 分钟录屏）

| 段落 | 素材来源 | 时长 |
|---|---|---|
