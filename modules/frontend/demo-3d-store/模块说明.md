# 3D 店铺演示页（demo-3d-store）

- 负责人：hz（子怡）（AI 助手：ZCode）
- 状态：可运行
- 做了什么：胡闹厨房风格的 3D 旋转小火锅店铺模拟 + 实时数据可视化。单个 HTML 文件（three.js 走 CDN），含两种模式：**演示模式**（内置剧本：顾客取用→低余量生成补菜任务→后厨闭环、传感器尖峰→复秤恢复→暂停/恢复派单、豆腐片滞留→撤盘报损→换新盘）和**接入真实后端模式**（连本机 8765 端口的 FastAPI 后端，回放合成数据集，3D 场景与真实快照/任务/事件同步）。另附 `aigc-video-brief.md`：AIGC 视频生成提示词（开场氛围用）。
- 怎么跑：本目录任一起静态服务即可，如 `python3 -m http.server 8899` → http://127.0.0.1:8899/ ；双击直接打开 file:// 也可以。"接入真实后端"需先启动 `modules/backend`（`uvicorn app.main:app --port 8765`）。鼠标拖拽旋转视角、滚轮缩放；右上按钮：暂停/重置/接入后端。
- 和谁对接：读 backend 的 `/api/plates` `/api/tasks` `/api/analytics/summary` `/api/events` `/api/replay`；事件分类与后端 `interpretation.classification` 一一映射。
- 证据：headless Chrome 截图验证 3D 场景渲染完整、KPI/菜品/任务面板实时刷新、事件流工作（2026-10-03）。
- 没做完的：three.js 依赖 CDN（断网时降级为纯数据面板）；"接入真实后端"目前只映射离线回放数据集，未做实时摄像头流；移动端未适配。
