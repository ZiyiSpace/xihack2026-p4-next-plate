# Jev-Omni 视觉识别服务（菜品识别）

- 负责人：chujieHong（AI 助手：DeepSeek Harness）
- 状态：**可运行** —— 服务器在线，已与 `modules/backend` 联调通过（认菜 8/8、事件对评 8/8）

## 做了什么

把 `akhilaaa3/Jev-Omni`（Gemma 4 12B 多模态**决策分类器**）部署到一张 AutoDL RTX 4090 上：
文本塔用 bitsandbytes 8bit 量化、视觉/音频投影层保持 BF16，常驻显存约 **13 GiB / 24 GiB**，
封装成 HTTP 接口，**只做菜品识别**。

它**不生成文字**：给它一张照片 + 一份候选菜名清单，它返回每一项的概率，一次前向出结果。
所以"识别"是**闭集选择** —— 候选清单由调用方给，清单越短越准。

识别准确率（真实照片实测，非合成图）：**8 道清单 8/8**、12 道 7/8、**40 道 6/8**。
置信度可以当过滤器：40 道那组里 ≥0.78 的 5 张全对，<0.40 的只对 1/3。

服务已接进 `modules/backend`（`app/jev.py` → `app/vision.py`），**开箱即用**，
后端 `.env` 里 `JEV_BASE_URL` 的默认值就是这台服务器。

## 怎么跑

### 用现成的服务器（推荐）

不用部署，直接用公网地址。在 `modules/backend/.env` 里填密钥即可：

```bash
cd modules/backend
cp ../model/.env.example .env
# 编辑 .env，填 JEV_API_KEY（密钥在群内文档里，不要提交）
../.venv/bin/uvicorn app.main:app --port 8000
```

### 本地调一下看看

最省事的办法：把后端跑起来，用它的交互式文档直接点着试。

```bash
cd modules/backend
cp ../model/.env.example .env     # 填 JEV_API_KEY
../.venv/bin/uvicorn app.main:app --port 8000
# 然后打开 http://127.0.0.1:8000/docs
```

只想验证这一个服务通不通、认菜准不准：

```bash
JEV_API_KEY=<群内密钥> python modules/integration/check_jev_contract.py
```

> 本目录**不放客户端代码**：唯一的客户端是 `modules/backend/app/jev.py`，
> 避免同一套 API 出现两份实现。外部调用方看 [`使用说明（转发给对方）.md`](使用说明（转发给对方）.md)。

### 自己从零部署

完整步骤见 [`README.md`](README.md)（环境、下权重、量化、开机自启、看门狗、故障排查）。

## 接口一览

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/v1/identify` | **菜品识别（主入口）**：照片 + 候选清单 → 菜名排名与置信度 |
| POST | `/v1/ask` | 通用提问：一句话 + 候选答案（可带图/音/视频） |
| POST | `/v1/decide`、`/v1/decide/upload`、`/v1/decide/multi` | 底层决策接口 |
| GET/POST/DELETE | `/v1/menu` | 候选菜名清单的增删查 |
| GET | `/ui`、`/docs`、`/health` | 网页版、交互文档、健康状态 |

鉴权：`Authorization: Bearer <密钥>` 或 `X-API-Key: <密钥>`。

## 没做完的 / 已知问题

1. **服务已移除 `/v1/portion` 与 `/v1/measure`**（菜量识别）。这是双方一致的结论：
   模型测菜量不可靠（百分比问法实测 0/5、单图档位 0/6），**量以称重规则为准**。
   但 `modules/backend/app/jev.py` 里仍留着这两个方法的定义，其中 `portion()` 被
   `replay.py:135` 调用 —— 现在会 **404 并重试 3 次、白等约 25 秒**（功能不受影响，只是慢）。
   详见 `../integration/验证记录.md`。
2. **密钥没有随仓库分发**（协议禁止）。谁要用，得先在群里拿密钥。
3. 单卡串行推理，**请勿并发**（并发超 2-3 会一起变慢）。
4. 模型对**长得像的菜**会错（饺子↔馄饨、糖醋里脊↔宫保鸡丁），加长清单救不回来。
5. 识别是闭集：清单里没有的菜，它也只会在清单里挑一个 —— 必要时开 `include_none` 允许"以上都不是"。
