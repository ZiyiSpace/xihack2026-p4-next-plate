## 契约速查（权威定义见 `modules/backend/README.md`）

| 前端要什么 | 调什么 | 备注 |
|---|---|---|
| 总览状态 | `GET /api/plates` + `GET /api/dishes` + `GET /api/tasks` | 盘子快照/菜品汇总/任务列表，拼成自己的 state |
| 任务操作（接单/完成/取消/延后） | `POST /api/tasks/{id}` | 状态机 pending→making→done；取消/延后必须带 note |
| 经营分析 | `GET /api/analytics/summary` | 排名/站点偏好/时段/每客口径 |
| 报损台账 | `GET /api/analytics/waste` | 撤盘记录进这里 |
| 观测输入（采集/模拟） | `POST /api/events/station`（传图用 `/upload`） | 幂等（event_id）、乱序隔离、尖峰不记账——**前端不要预处理，原样上报** |
| 后厨操作（补菜/撤盘/换菜） | `POST /api/events/operation` | 补菜记录自动闭环任务；撤盘带 disposal_reason |
| 模拟收银（人数） | `POST /api/analytics/covers` | 每客/每百客口径需要它 |

## 域模型映射（工作台原型 → 后端）

| 原型概念 | 后端对应 |
|---|---|
| `dishes`（12 道虚构菜 + capacity/batch/leadMinutes/safetyMinutes） | `dish_id`（D01–D06 真实目录）+ `PUT /api/dishes/{id}` 配置 prep_time_min/batch_size/unit_mass_g；菜名/菜品从 `GET /api/dishes/config` 拉真实目录 |
| `plates[].quantity / weightG` | `plates[].trusted_net_g / remaining_count`（克数与件数后端分开给） |
| `tasks` 状态 `pending/preparing` | 后端 `pending/making`（一字之差，注意映射） |
| `ledger` 的 `take/refill/waste` | `GET /api/events` 的 `interpretation.classification`（removal/refill_confirmed）+ `/api/analytics/waste` |
| `orders/guests`（营收模拟） | `POST /api/analytics/covers` + summary 里的 simulated_finance |
| 自带 `/api/state` `/api/actions` `/api/analysis` | 分别由上表三行组合替代 |
| 自带规则参数（噪声、闭店、补菜判定） | **废弃**；参数调整走后端配置（`backend/app/config.py` 环境变量或菜品配置接口） |
